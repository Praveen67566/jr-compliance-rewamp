## Implementation

- `/ads/bis` now permanently redirects to `/ads/bis-certification` using the existing `redirectPath` helper, preserving UTM values, repeated query parameters and empty values. The compatibility page is `app/ads/bis/page.tsx`; all rendered-page metadata, CTA events and new lead requests use `/ads/bis-certification`.

- `app/ads/bis-certification/page.tsx` renders a static App Router page with the existing metadata helper, an absolute `/ads/bis-certification` canonical and `noindex,nofollow`, matching the existing BIS ad campaign. It is not added to the sitemap.
- `data/bis-ads-fallback.ts` preserves the supplied campaign wording, all six assistance cards, six certification cards, six penalty cards, six benefits, six process steps, nine document categories, eight audience categories and ten FAQs. The ten requested sections appear in order.
- `lib/content.ts` supplies the typed static data, existing fallback footer/form settings and six existing approved client logos. This loader makes no Strapi request. `ConsultationForm` is reused directly; its five descriptive field labels are screen-reader-only, matching the verified live contact form and keeping the country-code prefix inside the phone field. The select remains keyboard accessible. `ServiceFaqList` and `StickyCtaBar` are reused without changes. `SitePageShell` has one optional header slot; its default still renders the existing `SiteHeader` on all other pages.
- Following the owner's visual correction, this route uses a dedicated campaign header: a slim navy announcement rail, full-width cool-white navigation with the JR logo, five internal links (Included, Cert Types, Benefits, Process, FAQ), and WhatsApp/Call/consultation actions. It is sticky with measured anchor clearance. The compact menu supports Escape, focus return and closing after section selection. The mobile form follows the heading before the supporting service/proof copy. The duplicate navigation below the hero is removed.
- The announcement now uses the owner's exact replacement copy: “Affordable BIS Certification with Expert Support | 5,000+ Certifications · Expert Standards Team”. The previous service list, badge and repeated hero statistic are removed from that strip. The hero copy is unchanged.
- Per the owner's explicit colour request, red warning accents are scoped to the penalties section: pale red section treatment, red title/badge/icon surfaces, distinct penalty icons, a warning callout and red card rules. The process retains the six-step rail and six-card order, with a continuous connector, stronger numbered nodes, icon cards, blue gradient accents and highlighted original time ranges. The shared form and global theme are untouched by this styling update.
- The page reuses the existing phone configuration and the WhatsApp destination from the existing static BIS campaign. It uses the Compliance Network palette, blue hero/footer fields, ice reading surfaces, approved Inter font, compact bold campaign headings, reference-style cards and a three-action closing row. The campaign now uses `ConsultationForm` without any `className` overrides: its original navy design, progress indicators, stacked fields, typography and button styling match the existing contact-page form. The page structure and content order are unchanged; section surfaces alternate cool white, ice blue and navy/cobalt to improve contrast. The existing white client-logo artwork is displayed on navy tiles without recolouring it. No competitor copy, branding, images, scripts or CSS were imported.
- The reference was inspected as rendered HTML and in Chrome on 19 November 2026: split hero/form, anchor navigation, three-column card groups, repeated consultation/WhatsApp actions, six-step process, documents, audience, FAQ and final CTA. Its offers, ratings, testimonials and scarcity messages were excluded.
- The form posts to the existing `/api/leads` endpoint. The new `/ads/bis-certification` identity (including a trailing slash) is included in the frontend lead classifier alongside the retained legacy campaign identity so this campaign reaches the existing `technical` destination. No API handler, transport, environment variable, backend or schema changed. `pathname` remains `/ads/bis-certification`; `page_name` is built by the existing transport. State is omitted because the existing contract has no State field.
- Existing UTM support is preserved: `utm_source`, `utm_medium` and `utm_campaign` reach `page_parameters`. The existing contract does not accept `utm_content`, `utm_term` or advertising click IDs; this work does not widen it or add browser attribution storage.
- CTA tracking uses the root `GTM-K938HN3` integration. This repository had no existing custom WhatsApp event publisher. The new route pushes `whatsapp_click` for WhatsApp and `cta_click` for consultation, phone and section navigation, with `page_path`, `cta_type` and `cta_location`. Both analytics and marketing permission are required; denied or revoked clicks are not queued. GPC suppresses marketing-dependent events. Contact fields and query strings are not sent in these events. The GTM container must have matching triggers if these events are to become reporting/conversion tags.
- The supplied `public/images/jrc-logo.png` is used by this campaign's header and sticky CTA only; shared website branding and the footer remain unchanged. Certification cards use consistent left-aligned text and shared row tracks so headings, descriptions and bullet lists align across each responsive row without truncating copy.
- The shared sticky CTA keeps its existing responsive behavior: on compact screens it appears only after the full form has passed above the viewport. Existing accessibility and privacy controls remain available.
- The static campaign data now fills that bar with ISI Mark/CRS/FMCS service copy, compliance-assessment and lab-testing support points, a third filing-support highlight for the compact layout, the existing JR logo and approved Sony/Tata Play artwork. The shared desktop support layout and compact highlight control are reused without modifying the shared bar component. The consultation CTA continues to return to the form, and WhatsApp clearance follows the bar's measured height.
- The campaign's local site settings enable the exact shared right-side floating WhatsApp button through `site.whatsAppHref`, using the existing campaign contact URL. Its green artwork, preview, Escape dismissal, reduced-motion behavior and clearance above the sticky CTA come from `SitePageShell` unchanged. Its click uses the campaign's existing consent-aware `whatsapp_click` tracking with `cta_location: site-chrome`. Other pages' settings are not mutated.

## Claims to resolve before production publication

The owner requested exact wording. The following statements remain in that supplied copy and require editorial/legal review before the page is published. A robots directive does not make the page private.

| Supplied claim/location | Required review |
| --- | --- |
| CRS card: attribution to the Ministry of Home Affairs | BIS identifies Electronics/IT CRS notifications with the Ministry of Electronics and Information Technology (MeitY). Correct the attribution after the owner approves revised copy. See [BIS Scheme II](https://www.bis.gov.in/product-certification/products-under-compulsory-certification/scheme-ii-registration-scheme/?lang=en). |
| FAQ 6: every Indian product needs a BIS licence; broad audience/product lists | BIS describes certification as generally voluntary, with compulsory requirements introduced for specified products through Quality Control Orders. Qualify by current product, scheme, effective date and exemptions. Check infant food, toys, jewellery, import and marketplace claims individually. See [BIS compulsory certification](https://www.bis.gov.in/product-certification/products-under-compulsory-certification/?lang=en). |
| Hallmarking card: gold and silver jewellery are universally mandatory | Check current orders, districts, grades, exemptions and jeweller obligations separately. BIS's October 2025 newsletter described the new silver HUID scheme as voluntary; do not assume identical rules for gold and silver. See [BIS jeweller FAQs](https://www.bis.gov.in/hallmarking-jewellers/?lang=en) and [BIS October 2025 newsletter](https://www.bis.gov.in/wp-content/uploads/2025/10/BIS-NEWSLETTER-OCTOBER-2025.pdf). |
| Penalty cards: automatic two-year first-offence imprisonment, ₹2–5 crore fine, destruction/seizure and court orders; FAQ 4: ₹2 lakh or two years | The amounts in the supplied cards and FAQ differ. Obtain an offence-specific legal review of maxima, minima, repeat-offence rules, discretion and enforcement powers under the current Act and amendments. Do not present a fixed penalty as universal. See [BIS Act 2016, especially section 29](https://upload.indiacode.nic.in/showfile?actid=AC_CEN_21_44_00008_201611_1517807328370&filename=A2016-11.pdf&type=actfile). The linked Act was located, but its PDF could not be fetched during this review; the figures have not been certified as correct. |
| Penalties introduction: 10,000+ checks and products worth 200 crore | Supply a dated primary enforcement report, reporting period, currency and matching figures. This statement was not independently substantiated. |
| Process estimates (days/weeks/months) and FAQ 7 (three weeks to six months) | Have the regulatory team confirm scheme-specific indicative ranges and starting points. These are neither guaranteed nor necessarily cumulative timelines. |
| “Our experienced consultants approve the BIS license quickly”; “Quick Approval”; protection from daily penalties | Clarify that BIS grants licences and JR Compliance provides consultancy. Approval, eligibility, revenue, tender access, global recognition and marketplace acceptance must not be guaranteed. |
| BIS laboratory recognition: NABL accreditation and audit always mandatory | Check the current laboratory recognition scheme, eligibility, accepted accreditation and relevant exceptions with BIS. |
| “India’s leading”, “India’s best”, FAQ 3 superlatives; 2000+ hero certifications, the owner's updated 5,000+ announcement claim, and 500+ categories | Retain supporting company records and an approved basis for comparisons/category counts, and reconcile the two supplied certification counts before publication. The header's 5,000+ wording is the owner's explicit update; the original hero statistic is preserved. No new ratings or testimonials were created. |
